✈️ MiPagina

MiPagina es una página web diseñada para ser útil, intuitiva y fácil de utilizar para todo tipo de usuarios.

El proyecto busca ofrecer una experiencia agradable mediante un diseño moderno, sencillo y atractivo, permitiendo a los usuarios navegar fácilmente por sus diferentes secciones y encontrar la información que necesitan.

🌎 Características

✈️ Interfaz sencilla e intuitiva.

📱 Diseño adaptable a dispositivos móviles.

🎨 Diseño moderno y atractivo.

🖱️ Elementos interactivos.

✨ Animaciones y efectos visuales.

🚀 Navegación rápida y sencilla.

🛠️ Tecnologías utilizadas

HTML5 — estructura de la página.

CSS3 — diseño, estilos y animaciones.

JavaScript — interactividad y funcionalidades.

💻 Ejecución del proyecto

Para ejecutar el proyecto localmente, abre una terminal dentro de la carpeta del proyecto y ejecuta:

py -m http.server 8000


Después abre tu navegador y entra en:

http://localhost:8000
